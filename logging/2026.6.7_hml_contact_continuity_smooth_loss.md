## 今日代码修改

修改文件：

```text
diffusion/gaussian_diffusion.py
utils/parser_util.py
utils/model_util.py
```

目标：

```text
1. 保留旧的 --lambda_hml_contact_geo 兼容性。
2. 把旧 geo loss 拆成可独立调权重的 slide / height / vertical。
3. 新增 contact continuity loss，优先压 no_contact_ratio。
4. 新增 contact-frame smooth loss，只在连续接触帧上压脚部二阶差分，避免粗暴全身平滑。
```

### 1. 新增独立权重

新增参数：

```text
--lambda_hml_contact_geo_slide
--lambda_hml_contact_geo_height
--lambda_hml_contact_geo_vertical
--lambda_hml_contact_geo_continuity
--lambda_hml_contact_geo_smooth
```

旧参数仍保留：

```text
--lambda_hml_contact_geo
```

含义不变，仍然只加旧三项：

```text
hml_contact_geo = hml_contact_geo_slide
                + hml_contact_geo_vertical
                + hml_contact_geo_height
```

这样旧实验命令不会坏；新实验可以只用拆分权重，避免重复加权。

### 2. contact continuity loss

接触 mask 继续沿用 eval 对齐口径：

```text
target_height[t] <= 0.05
AND target_vertical_delta[t] <= 0.02
AND frame[t] / frame[t+1] valid
```

新增项：

```text
pred_height_over =
  relu(pred_height - 0.05)

pred_vertical_over =
  relu(abs(pred_delta_y) - 0.02)

hml_contact_geo_continuity =
  mean(pred_height_over^2 + pred_vertical_over^2 over contact deltas)
```

目的：

```text
1. 不只是让 GT 接触帧上的脚少滑。
2. 还要让预测脚在 eval 判定里继续保持接触。
3. 主要针对 no_contact_ratio 升高的问题。
```

### 3. contact-frame smooth loss

新增项：

```text
pred_accel =
  pred_feet[t+2] - 2 * pred_feet[t+1] + pred_feet[t]

smooth_mask =
  contact_mask[t] AND contact_mask[t+1]

hml_contact_geo_smooth =
  mean(||pred_accel||^2 over continuous contact windows)
```

设计判断：

```text
1. 只约束脚部，不做全身 global jerk。
2. 只在连续接触窗口约束，不磨平非接触动作、跳跃、舞蹈和上肢表达。
3. 目标是降低接触期抖动，同时控制对 HumanML 主指标的副作用。
```

```text

--lambda_hml_contact_geo_vertical 0.01
```

主要观察：

```text
1. locomotion foot_sliding 是否继续低于 baseline。
2. locomotion no_contact_ratio 是否从 0.111304 拉回到接近 0.05。
3. normalized_jerk 是否不再明显高于 warmup / baseline。
4. step_timing_score 是否至少回到 geo_0p05 或 warmup 附近。
5. 如果 foot_sliding 仍低但 jerk 继续升，先降 smooth/continuity 权重，而不是加 global smooth。
```

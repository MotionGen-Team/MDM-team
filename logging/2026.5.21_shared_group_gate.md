# 2026.5.21 shared_group_gate 改进记录

## 今日目标

围绕 `plan_one_local_v2_shared_gate` 的评测结果，确认 local gate 对 foot contact / step timing 的影响，并在此基础上实现一版更保守的 per-group gate：

```text
left_leg  -> leg_gate
right_leg -> leg_gate
torso     -> torso_gate
```

这版不是替换旧的 `shared_gate`，而是新增 `shared_group_gate`，保证旧 checkpoint 和旧实验仍可复现。

## 一、推理级 local gate 扫描

基于同一个 checkpoint：

```text
checkpoints/plan_one_local_v2_shared_gate/model000200000.pt
```

新增评测参数：

```text
--local_gate_override
```

作用：

```text
只在 eval_motion_quality 从 checkpoint 采样时覆盖 target model 的 effective local_gate。
不改 checkpoint 文件。
不影响 baseline。
输出目录自动带 localgate_xxx 后缀，避免不同 gate 点互相覆盖。
```

服务器运行命令：

```bash
for g in 0 0.05 0.10 0.109132; do
  python eval/eval_motion_quality.py \
    --model_path checkpoints/plan_one_local_v2_shared_gate/model000200000.pt \
    --local_gate_override "$g" \
    --eval_num_samples 100 \
    --sample_batch_size 32 \
    --seed 10 \
    --device 0
done
```

输出目录：

```text
checkpoints/plan_one_local_v2_shared_gate/motion_quality_target_localgate_0_000200000_seed10_n100
checkpoints/plan_one_local_v2_shared_gate/motion_quality_target_localgate_0p05_000200000_seed10_n100
checkpoints/plan_one_local_v2_shared_gate/motion_quality_target_localgate_0p1_000200000_seed10_n100
checkpoints/plan_one_local_v2_shared_gate/motion_quality_target_localgate_0p109132_000200000_seed10_n100
```

## 二、local gate 扫描结果

关键指标均值：

```text
gate      foot_sliding  no_contact  L_contact  R_contact  step_cv  step_score  jerk_mean  jerk_p95   symmetry
0         0.01266       0.03043     0.95871    0.93782    0.54637  0.60889     0.00141    0.00499   0.91428
0.05      0.00542       0.06722     0.91410    0.91917    0.67137  0.53600     0.00194    0.00763   0.91348
0.10      0.00888       0.09398     0.83569    0.80731    0.74876  0.48787     0.00578    0.02146   0.93941
0.109132  0.00938       0.10577     0.80702    0.77017    0.76362  0.48649     0.00689    0.02529   0.94058
```

结论：

```text
no_contact_ratio 随 local_gate 增大几乎单调上升：
0.030 -> 0.067 -> 0.094 -> 0.106

left_contact_ratio / right_contact_ratio 持续下降。
step_timing_cv 持续上升，step_timing_score 持续下降。

这基本坐实：
local 进入 fusion 越强，模型越倾向通过减少脚接触来规避 foot_sliding。
```

同时：

```text
foot_sliding 不是单调变化。
gate=0.05 时 foot_sliding 最好，继续增大 gate 后 foot_sliding 反而回升。
```

因此当前不是 simple scalar gate 调大/调小就能解决，而是 local 信息有价值，但需要更细粒度地限制进入 fusion 的位置和强度。

## 三、结构判断

不建议继续只扫单个 scalar gate，原因：

```text
scalar gate 只能整体压 local。
它不能表达“腿脚相关 local 要保守，躯干/上身 local 可以适当保留”。
```

也不建议第一步就做完全独立的三组 gate：

```text
left_leg gate
right_leg gate
torso gate
```

原因：

```text
左右腿完全独立 gate 可能重新引入 leg asymmetry。
当前更稳的第一版是左右腿共享一个 gate。
```

因此本轮实现：

```text
shared_group_gate:
left_leg / right_leg 共用 leg_gate
torso_upper 使用 torso_gate
```

## 四、代码改动

### 1. eval_motion_quality 支持推理级 local gate override

文件：

```text
eval/eval_motion_quality.py
```

新增参数：

```text
--local_gate_override
```

实现逻辑：

```text
local_gate = sigmoid(local_gate_logit) * local_gate_max

给定目标 effective local_gate 后，反推 local_gate_logit：
prob = local_gate / local_gate_max
logit = log(prob / (1 - prob))
```

特殊情况：

```text
local_gate = 0 时使用 logit = -100.0 近似关闭。
```

### 2. LocalBranch 新增 shared_group_gate

文件：

```text
model/plan_one/local_branch/local_branch.py
```

新增 variant：

```text
shared_group_gate
```

结构：

```text
left_leg / right_leg:
  共享 leg_temporal
  共享 leg_gate

torso_upper:
  使用 torso_temporal
  使用 torso_gate

group self-attention:
  仍关闭
```

gate 设计：

```text
leg_gate_max = 0.12
torso_gate_max = 0.25

leg_gate = sigmoid(leg_gate_logit) * leg_gate_max
torso_gate = sigmoid(torso_gate_logit) * torso_gate_max
```

初值：

```text
leg_gate ~= 0.05
torso_gate ~= 0.05
```

对应 logit：

```text
leg_gate_logit = logit(0.05 / 0.12) = -0.3364722
torso_gate_logit = logit(0.05 / 0.25) = -1.3862944
```

## 七、后续观察指标

优先观察：

```text
foot_sliding
no_contact_ratio
left_contact_ratio
right_contact_ratio
double_support_ratio
step_timing_cv
step_timing_score
local_accel_mean
local_jerk_mean
local_jerk_p95
normalized_jerk
leg_motion_symmetry
```

理想结果：

```text
foot_sliding 接近 gate=0.05 的低值。
no_contact_ratio 不再接近 shared_gate 当前学习值 0.109132 的高值。
left/right contact ratio 不再明显下降。
step_timing_score 不再明显低于 baseline/full。
leg_motion_symmetry 保持接近 shared_gate 的改善，不回到 full/local 旧问题。
```

如果结果成立：

```text
说明 local 信息确实有价值，但腿脚相关路径需要比 torso 更保守。
后续可以继续做 foot/contact-aware gate 或脚部通道限幅。
```

如果结果不成立：

```text
如果 no_contact_ratio 仍高，说明问题不只是腿部 group 幅度，可能还在 fusion projection / LayerNorm / base head 对 local 方向的重放大。
如果 foot_sliding 回到 gate=0 的水平，说明 leg_gate_max=0.12 可能过保守，后续可试 leg_gate_max=0.15 或改为 contact-aware temporal mask。
```

# 2026.6.13 HumanML locomotion no-contact metric and coverage loss

## 今日结论

6.8 的 `plan_one_warmup_hml_contact_geo_cont_smooth_gate_locomotion_0p01`
已经完成 `motion_quality n=100 @ model000200000 seed=10` 评测。

原始 overall 指标：

```text
metric                  baseline    cont_smooth_0p01    gate_locomotion_0p01
foot_sliding             0.011008    0.009682           0.010895
no_contact_ratio         0.051243    0.087828           0.085608
step_timing_score        0.564142    0.526857           0.540439
normalized_jerk          0.325002    0.454804           0.454566
local_jerk_p95           0.023421    0.023607           0.026733
contact_height_var       0.000224    0.000179           0.000184
```

判断：

```text
1. locomotion_text gate 对 step_timing_score 有正收益，从 0.526857 回升到 0.540439。
2. no_contact_ratio 只从 0.087828 小幅降到 0.085608，仍明显高于 baseline 的 0.051243。
3. foot_sliding 从 cont_smooth 的 0.009682 回退到 0.010895，脚滑收益基本被吃掉。
4. normalized_jerk 几乎没有改善，仍比 baseline 高约 40%。
5. 因此 gate_locomotion_0p01 不建议作为主结果。
```

同时发现一个评测口径问题：

```text
eval_motion_quality.py 在传 baseline_path 时，会用 baseline 的 sample_index 分组覆盖 target 的 motion_group。
但当前 baseline results 和 target results 的文本并不逐样本一致，导致 grouped_summary 被污染。
```

修正后新增主要观察指标：

```text
locomotion_no_contact_ratio
```

它只在各自结果的 `motion_group == locomotion` 样本上统计 `no_contact_ratio`。

用现有 6.8 gate 结果重算：

```text
target   locomotion_no_contact_ratio = 0.068795, count=51
baseline locomotion_no_contact_ratio = 0.045955, count=46
```

结论：

```text
1. no_contact_ratio 作为全局指标不够科学，容易被 static / airborne 文本影响。
2. locomotion_no_contact_ratio 更适合作为当前接触连续性主指标。
3. 但它仍是 eval metric，不适合直接用硬阈值 ratio 训练。
4. 训练侧新增 soft coverage loss，更直接约束 locomotion 下“至少一只脚覆盖地面”。
```

### 1. 新增 locomotion no-contact summary

`eval/eval_motion_quality.py` 新增 summary 指标：

```text
locomotion_no_contact_ratio
```

实现逻辑：

```text
1. 保留逐样本 no_contact_ratio 原始定义。
2. summarize_rows 额外收集 motion_group == locomotion 的样本。
3. 只对这些样本的 no_contact_ratio 求 mean / std / count。
4. comparison 和 print_summary 都纳入该指标。
```

同时删除 baseline 分组覆盖 target 分组的逻辑：

```text
旧逻辑：
baseline_groups = {sample_index: motion_group}
target_rows[same sample_index].motion_group = baseline_group

新逻辑：
baseline 和 target 各自按自己的 text / motion 特征分组。
```

### 2. 新增 coverage loss

新增训练参数：

```text
--lambda_hml_contact_geo_coverage
```

接入范围：

```text
diffusion/gaussian_diffusion.py
utils/parser_util.py
utils/model_util.py
```

coverage loss 设计：

```text
1. 使用 target recover_from_ric 后的脚部几何，按 eval 对齐阈值得到 target contact mask。
2. 对每个 target 任一脚接触的帧，计算 pred 四个脚点的 contact error。
3. contact error = height_over^2 + vertical_over^2。
4. 每帧取四个脚点中的最小 error，表示“至少一只脚应该能覆盖接触”。
5. 对 target_any_contact 帧求均值。
```

核心设计判断：

```text
1. 不直接优化硬 no_contact_ratio，避免不可导阈值和 bool any。
2. 不强行指定某一只脚接触，允许模型左右脚相位有少量偏移。
3. coverage loss 跟 slide / height / vertical / continuity / smooth 一样受 hml_contact_geo_gate 控制。
4. 推荐先在 locomotion_text gate 下使用。
```

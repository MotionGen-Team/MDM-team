## 今日代码修改

修改文件：

```text
diffusion/gaussian_diffusion.py
utils/parser_util.py
utils/model_util.py
```

新增参数：

```text
--hml_contact_geo_gate
```

可选值：

```text
none             默认值，不启用门控，保持旧实验兼容
locomotion_text  只在文本命中 locomotion 关键词时启用 HumanML recover_from_ric foot geometry losses
```

门控范围：

```text
hml_contact_geo_slide
hml_contact_geo_vertical
hml_contact_geo_height
hml_contact_geo_continuity
hml_contact_geo_smooth
hml_contact_geo
```

不受影响的项：

```text
hml_contact
hml_contact_vel
rot_mse
其它已有 loss
```

`locomotion_text` 当前关键词：

```text
walk
run
jog
step
stroll
pace
march
limp
skip
move forward
moves forward
walking
running
```

同时排除明显 airborne 文本：

```text
jump
hop
leap
air
kick
vault
```

设计判断：

```text
1. 训练 batch 已经有 model_kwargs['y']['text']，不需要改 dataset。
2. 先用文本启发式门控，和 eval_motion_quality 的 motion_group 文本口径保持接近。
3. 默认 none，避免破坏旧 checkpoint / 旧命令。
4. 门控只乘每个样本的 geo loss 标量，不改变 recover_from_ric 和基础 mask 计算。
```
